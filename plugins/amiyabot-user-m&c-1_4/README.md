- 发送 `兔兔` 会随机回复表情包
- 发送 `兔兔签到` 可以进行每日签到
- 发送 `兔兔查看我的信息` 查看你的个人记录
- 发送 `兔兔开启/关闭戳一戳` 可以开启和停用本插件的戳一戳响应

## 心情事件
- 说了兔兔的坏话或者骂了兔兔，兔兔的心情值会下降。降低到一定程度，就不会再理博士了哦。
    - 和兔兔道歉可以恢复心情值

## 打招呼
_“兔兔早上好~”_
- 和兔兔打招呼也可以进行签到

## 随机事件
- 签到时会触发随机事件

## 不要说兔兔是驴！
兔兔会生气哒！

## 添加表情包
把表情包图片放到文件夹 resource/plugins/user/face 下即可
