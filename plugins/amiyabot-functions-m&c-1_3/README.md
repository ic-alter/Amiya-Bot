### 查看并管理已安装的插件
- 发送 `兔兔功能` 查看已安装的插件
- 发送 `兔兔功能+插件名` 查看相应插件详细信息
- 频道/群管理员发送 `兔兔开启功能/关闭功能` 可开关单个功能
